One last text from a phone battery to its charger, 151 characters:

> i waited all day and you show up with a frayed cable and 5 watts. fine. i'm dying at 1%, and my last words go to the power bank. it actually showed up.

The setup is the wait: all day for a charger that arrives late, frayed and
slow. The turn is the will: the battery's last words go to its rival, the
power bank, because that one actually showed up. A breakup text with a
jealousy triangle, not another dying-battery complaint.

## Run it

```sh
node main.ts
```

It prints the line and writes it to `/output/entry.txt`.
